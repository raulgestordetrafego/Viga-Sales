## Quick Summary
Meta Ads opera com 3 níveis: Campanha → Conjunto de Anúncios → Anúncio. CBO (orçamento de campanha) é preferível ao ABO. Estratégia de lance padrão é "valor/volume mais alto". 5 maneiras de segmentar: automática, direcionamento detalhado, controle de público, via pixel, via anúncio. O anúncio deve ser FILTRO, não ímã. Mantenha 6 anúncios rodando + 6 prontos. Nomenclatura traz ROI.

## Estrutura e Hierarquia

| Nível | Pergunta que responde |
|-------|----------------------|
| Campanha | Por que anunciar? Quanto gastar? |
| Conjunto de Anúncios | Para quem? Onde? |
| Anúncio | O que anunciar? |

### Nomenclatura (traz ROI)
- **Campanha**: `[OBJETIVO] [AQUECIMENTO] [POSICIONAMENTO] [TAG] Descrição`
- **Conjunto**: `(Nº) - [AUTO] - [Nome do público]`
- **Anúncio**: `AD (nº) - Descrição identificável`
- Tags de aquecimento: `[F]` Frio, `[M]` Morno, `[Q]` Quente

## Objetivos de Campanha
| Objetivo | Metas de Desempenho |
|----------|---------------------|
| Reconhecimento | Alcance, Impressão, Incrementalidade |
| Tráfego | Clique no link, Visualizações de página |
| Engajamento | Visualização de vídeo, Msg (WhatsApp/Direct), Interação |
| Cadastro | Site, Formulário instantâneo |
| Venda | Site (requer pixel+API), Catálogo (anúncios dinâmicos) |

## Orçamentos

| Escolha 1 | Escolha 2 |
|-----------|-----------|
| **CBO** (nível campanha) — Meta distribui verba | **Diário** — controle a cada 24h (mais usado) |
| **ABO** (nível conjunto) — você define por segmentação | **Total (vitalício)** — ideal para negócios físicos com horários |

**CBO**: melhores resultados, menos trabalho. Use limites de gasto mínimo/máximo.
**ABO**: mais controle, ideal para isolar variável "gasto" em testes.

## Estratégias de Lance
- **Valor/Volume mais alto** (padrão/recomendado) — máximo de resultados dentro do orçamento
- **Limite de lance** — define lance máximo
- **Meta de custo por resultado** — mantém custos próximos de um valor-alvo
- **Meta de ROAS** — retorno sobre investimento (bom para e-commerce)

> Na Meta, lance e orçamento estão ATRELADOS. Para diminuir o lance, diminua o orçamento.

## Segmentação — 5 Maneiras
1. **Segmentação automática** (Público Advantage) — Meta escolhe
2. **Direcionamento detalhado Advantage** — com base em comportamento/interesses
3. **Controle de público-alvo** — limitação de audiência (desative expansão ao usar "original")
4. **Via pixel** — dados coletados direcionam anúncios
5. **Via anúncio** — o que está escrito/falado é o MAIOR direcionador (anúncio = filtro, não ímã)

### Tipos de Públicos Disponíveis
Públicos automáticos, personalizados (remarketing), semelhantes (lookalike), demográficos, direcionamento detalhado.

### Regra do "E" e do "OU"
- **E** (limitador): TODOS os critérios simultaneamente
- **OU** (adicionador): PELO MENOS UM critério

## Recursos Advantage
- Campanha Advantage, Orçamento Advantage (CBO), Público Advantage, Posicionamento Advantage
- **Advantage não é sua estratégia; é PARTE dela**
- Teste em diferentes partes do funil

## Posicionamentos
- **Advantage Plus (automático)** — MAIS RECOMENDADO
- **Manual** — quando tem dados que justifiquem
- Ofereça formatos variados (1:1, 9:16, 16:9) para o automático funcionar melhor

## Pixel e API de Conversões
- Eventos padrão, eventos personalizados, conversões personalizadas
- API de Conversões = potencializador (instalação obrigatória)

## Fase de Aprendizado
- Toda campanha passa por: aprendizado → aprendizado limitado → ativa
- Para superar: aumentar orçamento, fundir conjuntos, ter pixel aquecido
- Às vezes a melhor ação é NÃO FAZER NADA e esperar

## Boas Práticas de Criativo
- 6 anúncios rodando + 6 prontos (total 12)
- 10+ variações do anúncio vencedor
- Técnicas: variações de cor/título/design, finais diferentes, formatos diferentes
- Anúncio deve ser FILTRO, não ímã

## Anti-Padrões
- ❌ Perfil Criador de Conteúdo em vez de Comercial no Instagram
- ❌ Público bom salva anúncio ruim (NÃO SALVA)
- ❌ Segmentação automática como única estratégia
- ❌ Otimizar antes da fase de aprendizado terminar
- ❌ Não ter variações suficientes de anúncios
- ❌ Não documentar otimizações (maior causa de demissão)
