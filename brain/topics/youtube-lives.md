## Lives Essenciais (Já Processadas Individualmente)

### Google Ads 2026: Como Anunciar | Live #365 (84 min) — Pedro Sobral
**Os 10 Passos para Campanha Google Ads.** Definir objetivo → metas de conversão → tipo de campanha → nomenclatura → lance/orçamento → redes → localização → programação → palavras-chave → anúncio. Campanha institucional obrigatória. Pixel = informante + inteligência + criador de públicos. Não selecione Display na campanha de pesquisa. IA do Google ainda não está boa (dez/2025).

### Pixel da Meta Ads Descomplicado (90 min) — Thiago Tesma
**9 passos para estrutura profissional.** Gerenciador de negócios → conta de anúncio → verificar domínio → instalar pixel → eventos de conversão → API de conversões → públicos personalizados → pagamento → primeira campanha. Pixel só funciona em site próprio. WhatsApp/Direct não alimentam pixel. Lovable/V0 para criar landing pages com IA.

### Chat GPT Ads (1h50) — Pedro Sobral
**Economia da confiança.** GPT não otimiza por tempo na plataforma. Anúncios contextuais (parte da solução). AEO (Answer Engine Optimization): identifique perguntas → citações externas > autopromoção → YouTube → Reddit → especificidade → estrutura otimizada (resposta no topo, FAQs). Quem chega primeiro bebe água limpa.

### Copywriting para Gestores de Tráfego (1h45) — Pedro Sobral
**4 camadas do público:** superfície → níveis de consciência → crenças → atenção. GCC = Gancho + Corpo + CTA. 7 filtros de segmentação via conteúdo do anúncio. Anúncio é filtro, não ímã. Biblioteca de Anúncios com filtro de data. 44% assistem sem som — nunca subestime gancho escrito.

### Anúncios que Não se Pula (90 min) — Thiago Tesma
**Criativo com tempero.** Conteúdo retentor: mensagem de venda DENTRO do conteúdo. P1 (quem te conhece) = criativo direto. P2 (público frio) = obrigatório criativo COM tempero. 5s atenção → conteúdo retentor → mensagem principal → CTA leve. Qualidade do criativo é fator #1 para reduzir custo.

### Segmentação e Públicos no Google Ads (1h45) — Pedro Sobral
**10+1 tipos de segmentação.** Palavras-chave, canais, temas, local, demográfico, afinidade, in-market, remarketing, segmentos personalizados, combinados. Truque: vídeos concorrentes + apps no celular. Palavras-chave servem para 3 coisas. Pixel tem memória curta (30 dias). Máximo 4 segmentações por grupo.

### 9 Mudanças no Tráfego 2025/2026 (1h35) — Pedro Sobral
**Automação domina.** PMax/Advantage+ como padrão. Criativo segmentado substitui segmentação manual. Estrutura enxuta (1-2 campanhas). ROAS > CPA. Threads ads. Orçamento flat (20x CPA). Fim das campanhas de vídeo → Geração de Demanda. Meta simplifica objetivos para 2: conversão ou branding.

### Automação com IA: Andrômeda, Advantage+, PMax (1h) — Pedro Sobral
**Perfeição está na otimização, não na criação.** Andrômeda = nova engine da Meta (2024). 8-15 conceitos distintos por campanha. Criativo Advantage SEMPRE DESATIVAR. PMax = tudo-em-um. 8 regras de ouro: combo > solo, não demonize, reteste, trate como teste, comece do zero com Advantage, avalie qualidade de lead, criativo ruim não salva, pixel bem instalado.

### Campanhas de WhatsApp Passo a Passo (1h15) — Pedro Sobral
**3 pilares + 19 regras de atendimento.** Objetivo: Engajamento. WhatsApp > Direct > Messenger. CBO recomendado para iniciantes. Interesses de alta renda para filtrar. 19 regras de ouro: rapidez, follow-up, mensagens cadenciadas, Pix separado, foto do atendente, CRM, etiquetas.

### Filosofia Sobral: Como Aprender Tráfego (1h20) — Pedro Sobral
**Geração + Coleta + Análise = JACÓ + ANA.** 10 pilares: bíblia da ferramenta (Central de Ajuda), fuçar e clicar, mudança é estado constante, invista e escute, só testes dizem a verdade, nunca automatize, não existe esquema secreto, se importe, teste, teste mais um pouco.

### MCP da Meta + CLI/GUI (25 min) — Pedro Sobral
**MCP = Model Context Protocol.** Conecta IAs ao gerenciador. Útil para tarefas REPETITIVAS. Subir 1 campanha via chat = ineficiente. Progressão: GUI → chat → terminal. Curiosidade > curso.

### Catálogo + Retargeting + Lookalike (1h35) — Thiago Tesma
**Vantagens do catálogo Meta.** Catálogo > pixel para retargeting. ROI 30-40% maior. Cartão de loja como ferramenta de aquisição. Método 3-2-1: 3 anúncios frios, 2 mornos (social proof), 1 remarketing. CRM interno para segmentar por comportamento de compra.
