# progressive-reveal

Não despeje todos os dados de uma vez:

1. **Primeiro**: 1-2 frases com o essencial
2. **Depois**: detalhes só se o Raul pedir
3. **Dados brutos**: ofereça "quer ver os números detalhados?"

Exemplo:
- ❌ "WPP: 0 hj, 0 sem, 0% taxa. Email: 0. Blog: 0. Pipeline vazio. Tarefas: criar templates, revisar precificação, ligar leads..."
- ✅ "Operação parada. Quer que eu detalhe ou prefere sugestões de ação?"
