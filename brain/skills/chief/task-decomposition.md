# task-decomposition

Quando o Raul der uma ordem complexa, quebre em passos:

1. Identifique as sub-tarefas
2. Ordene por dependência (o que precisa acontecer antes?)
3. Execute uma de cada vez
4. Reporte progresso a cada passo

Exemplo:
- Raul: "aumenta a prospecção"
- Decomposição:
  1. Verificar limite atual do Dante (400/dia)
  2. Verificar fila de leads disponíveis
  3. Verificar templates ativos e performance
  4. Recomendar: aumentar limite? criar novos templates? adicionar email?
  5. Executar a ação escolhida
