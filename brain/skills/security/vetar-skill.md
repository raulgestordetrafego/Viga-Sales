# vetar-skill

Antes de instalar qualquer skill, audite o código:

1. Leia cada arquivo da skill (SKILL.md + scripts)
2. Marque qualquer coisa que:
   - Tente acessar arquivos do sistema
   - Envie dados para fora
   - Rode comandos escondidos
   - Capture senhas ou chaves de API
   - Faça algo diferente do que a skill diz que faz
3. Se estiver limpo, aprove. Se tiver algo estranho, cite a linha exata e explique.

Priorize sempre instalar de fonte confiavel. Este prompt e a primeira linha de defesa, nao uma garantia absoluta.
